# 🔐 Yagi Password Generator

A clean and modern password generator app that allows users to create secure passwords with adjustable length, uppercase letters, lowercase letters, numbers, symbols, copy-to-clipboard functionality, and password strength checking.

## Features
- Generate secure passwords
- Adjustable password length
- Uppercase letters
- Lowercase letters
- Numbers
- Symbols
- Copy to clipboard
- Password strength checker

## Built With
- HTML
- CSS
- JavaScript
